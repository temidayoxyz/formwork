# Formwork

Architecture & Urban Design — Copenhagen. A multi-page portfolio site for a civic architecture studio.

## Concept

Formwork is a fictional 48-person architecture studio based in Copenhagen, founded in 2009. The studio specializes in civic and cultural buildings — libraries, concert halls, and public institutions across Scandinavia.

## Design Direction

- **Visual style**: Dark utilitarian / Scandinavian technical
- **Typography**: Space Grotesk (sans) + IBM Plex Mono (mono)
- **Palette**: Dark charcoal (#101214) with steel blue accent (#4A7C9B)
- **Imagery**: Architecture photography — concrete, geometric forms
- **Motion**: Subtle scroll reveals
- **Architecture**: Multi-page (Home, Work, Studio, Contact)

## Stack

- Vite
- Vanilla HTML/CSS/JS
- Google Fonts

## Pages

- `/` — Homepage with hero, selected work, approach, capabilities, numbers, current projects, recognition
- `/work.html` — Full project index and featured work gallery
- `/studio.html` — About the studio, how we work, leadership team, studio stats
- `/contact.html` — Contact info and project inquiry form
